# Blue Ocean Market V24.7

## Excavator supplier and machine usability update

- Removed `Action → Machine` from the Excavator Suppliers list.
- Added Delete Supplier with historical asset preservation: existing deals keep their data and have the supplier link cleared.
- Redesigned supplier machine view to show complete machine details.
- Added Edit and Delete actions for supplier-listed machines.
- Added sort and filter controls to Excavator Machines / Deals.
- Supplier search now includes supplier name and location.
- Supplier-listed machines are automatically removed from the available list when a matching machine is purchased or sold.
- Purchased supplier history remains visible, including completed/sold deals.
