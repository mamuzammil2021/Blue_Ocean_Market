Live backend runtime note
The Express/SQLite server was not launched in this build container because installed dependencies are incomplete and npm registry access is unavailable. This audit therefore does not claim live end-to-end HTTP runtime coverage. Run npm ci && npm run qa:runtime in the normal networked Node 22 test environment before production acceptance.
