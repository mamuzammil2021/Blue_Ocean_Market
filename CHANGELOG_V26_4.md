# Blue Ocean Market V26.4.0

## Excavator Buyer + Sell Machine integration
- Added buyer Local/International type and country flag UI.
- Added normalized buyer advance allocation ledger supporting partial allocation across multiple payments.
- Existing buyer selection in Sell Machine now displays complete buyer identity and available advance.
- Completed sales allocate 100% advance to the machine and update Buyer records.
- New buyers entered during Sell Machine are automatically created and their sale payment is recorded/allocated.
- Buyer detail now shows payment availability and allocation history.
- Pakistan resale-profit section is restricted to Pakistani buyers at API and UI level.
- Sale PDF now reports actual buyer type and advance allocation instead of a misleading outstanding balance.
- Preserved the rule that a machine cannot be sold until purchase price is fully paid.
