# Blue Ocean Market V24.8

## Excavator changes
- Block machine sale until purchase price is fully paid.
- Add Payment: payment date and reference mandatory; status is automatic Paid; receipt upload supported.
- Payment receipts are linked to the payment and stored in Documents with payment details in the document title.
- Current Stage no longer permits manual Exported or Sold / Completed.
- Sell Machine validates mandatory sale data and automatically sets Sold / Completed; no sale-payment completion condition is used because sale is 100% advance.
- Generate and store a PDF sale document containing the sale screen details.
- Supplier available listings are removed when matching machines are purchased or sold.
