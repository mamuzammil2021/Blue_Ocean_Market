# Blue Ocean Market V14

This version implements the recorded architecture and Excavator operating model.

Base currency for Excavator: KRW.

Run:
1. Install Node.js compatible with your Intel Mac/macOS 11 environment.
2. `npm install`
3. `npm start`
4. Open `http://localhost:3000`

CEO login for local testing:
`admin@blueocean.local`
`Admin@123`

Select a business from the top Workspace toggle, then click Dashboard. Only that business unit's dashboard is displayed. Select All Business Units for the consolidated CEO dashboard.
