- Added core CRUD controls for products/services, tasks, meetings and users.
- Added safe archive/deactivate/void behavior for historical records.
- Added business-unit deletion guard when historical records exist.

- Added sale detail endpoint for receipt generation.
- Added additional CRUD APIs for finance, purchases, CRM, KPIs, documents and meeting actions.
- Updated health/version marker to 5.0.0.
