# Blue Ocean Market V18 — Simple Excavator Operations

This version redesigns Excavator Operations around the user's simple workflow:

1. Buy Machine
2. Add Costs as they happen
3. Sell Machine
4. Record Payments
5. Keep multiple Documents

Each machine/deal is a persistent record that can be saved and reopened later.

## Add Costs
Cost types include:
- Logistics
- Repair
- Parts
- Customs Duty
- Tax / VAT
- Shipping / Freight
- Commission
- Documentation / Clearance
- Other Cost

Each cost can be marked whether it is included in machine cost. KRW is the base currency.

## Sale
A single Sell Machine form supports:
- Local Sale — Korea
- Export Sale
- Customer
- Sale date
- Selling price
- Payment status
- Export destination and shipping reference

## Documents
Multiple documents can be uploaded at any time and grouped by stage. Previous files are retained.

## Dashboard
The top business-unit toggle controls the active dashboard. Selecting Excavator and opening Dashboard shows only the Excavator dashboard/data.
