# Blue Ocean Market V8 — Restaurant & POS Upgrade

## Mandatory MIMI Resturant upgrades
- Fixed MIMI business workspace dashboard with live unit-scoped metrics.
- Added dedicated Menu Management.
- Added MIMI Stock Management with receive, issue, adjustment and waste movements.
- Added Weekly Menu planning with publish/draft state and meal periods.
- Added Buffet Management with date/time, price, capacity, status and menu selection.
- Added Open Orders workflow with reopen/continue, add/remove items, quantity changes and permitted price overrides.
- Open orders can be saved and later closed/paid; closed orders cannot be ordinarily edited.
- Dine-in table assignment validates availability and synchronizes table state with open orders.
- Added receipt printing support and retained reprint flow.
- Added optional advanced POS settings for reservations, split bill/payment, KOT/KDS, waiter assignment, table cleaning, delivery, printer routing and related features.
- Maintained business-unit isolation: MIMI data is scoped to MIMI and CEO can access all units.
