# Blue Ocean Market V27.4.0

V27.4 focuses on Finance verification/control, platform-wide navigation, notification panel usability, live-data synchronization, and Git/Render live-testing readiness while preserving V27.3 Meetings and all V27.2/V27.1 Excavator, Approval, Task, Performance and reporting functionality.

## Run locally
```bash
npm install
npm run qa:current
npm start
```
Open `http://localhost:3000`.

## Health
`GET /api/health` should return version `27.4.0`.

See `CHANGELOG_V27_4.md` and `LIVE_GIT_RENDER_TESTING.md` before pushing to Git/Render.
