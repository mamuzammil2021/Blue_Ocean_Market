# Blue Ocean Market V17 — Excavator Operations Rebuild

This version rebuilds the Excavator Operations UI around the recorded business workflow:

- One Excavator dashboard selected by the top business-unit toggle.
- Visible operation areas: Overview, Machines/Deals, Transactions, Parts Inventory, Documents, History.
- Persistent machine/deal workspace from purchase through local sale or export.
- Separate transaction entries for Purchase, Logistics, Repair, Part Purchase/Used, Other Cost, Local Sale, Export Sale, Purchase Payment and Sale Payment.
- Lifecycle can be paused and resumed; stage changes are retained in history.
- Multiple documents per stage are supported.
- Parts inventory supports new/used parts for repair or separate sale/export.
- KRW is the current Excavator base currency.
- CEO can permanently delete a machine; normal users do not receive that action.
- Responsive operation cards, tabs, tables and machine workspace.

This build should be tested on the user's Mac because live dependency/database execution is not available in the build environment.
